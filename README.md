<h1>3D Mechanics Simulator</h1>

An interactive 3D physics simulator built with TypeScript and Three.js, using classical A-level mechanics through real-time particle motion, gravity and collisions.

<h3>Overview</h3>

This project simulates particles moving inside a 3D environment including gravity and ball collisions.

The goal is to provide an interactive visual simulation of A-level Further and regular mechanics problems in real time, to support understanding.

<h4>Features:</h4>

3D particle simulation

Gravity

Sphere-to-wall collision detection

Sphere-to-sphere collision detection

Coefficient of restitution

Adjustable simulation speed

Simulation Diagnostic tools

Individual Custom Ball settings 

Adding/Removing Balls from Simulation

Restitution settings

Adjustable Simulation space size
